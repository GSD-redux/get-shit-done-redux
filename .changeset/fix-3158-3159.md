**Branch protection and background dispatch bypass** — `gsd_run query commit` now aborts early if the resolved branch points at an integration branch (`main`/`develop`) instead of silently pushing phase commits to it (#3158). Added a `workflow.background_dispatch` config flag to opt out of backgrounding the executor subagents, which prevents `run_in_background: true` from terminating one-shot sessions early (#3159).
